This repository contains the implementation of the ECDSA digital signature algorithm on the SpeedyChain blockchain, carried out for the Computer Science Course Conclusion Work at PUCRS.

The digital signature algorithm was also changed to RSA due to the end of support for the PyCrypto library.

The updated source code for the blockchain can be found in this [repository](https://github.com/conseg/speedychain).
